## Goal
Compose skeleton: `docker-compose.yml` using `include`, one file per profile in
`compose/` (`core.yml`, `services.yml`, `frontend.yml`, `observability.yml`,
`aws-local.yml`), networks `public`/`services`/`data`, Compose profiles and
`.env.example`. `make up` starts the (still empty) project.

## What Was Done
- `docker-compose.yml`: `name: aaas`, five `include` entries, networks
  `public` (`aaas-public`), `services` (`aaas-services`) and `data`
  (`aaas-data`, `internal: true`).
- `compose/{core,services,frontend,observability,aws-local}.yml`: one file per
  profile, each with a file header naming the owning team and the step that
  adds its services; `services: {}` until then.
- `compose/README.md`: file-to-profile table, network membership table and the
  rules every service block must follow.
- `.env.example`: `COMPOSE_PROFILES`, optional `DOCKER_DEFAULT_PLATFORM`,
  `AAAS_ENV`, `AAAS_BOOTSTRAP`, and the section where `new-service.sh` will
  append database credentials until they move to OpenBao (P5.3).
- `Makefile`: `make up` prints a notice and exits 0 when the selected profiles
  define no service (Compose itself fails with "no service selected").
- `docs/adr/0003-compose-network-topology.md`.
- README: repository map lists `docker-compose.yml` and `compose/`.

## Verification
- `docker compose config` — merged model renders (`name: aaas`, no services).
- `docker compose --profile services config --format json` with a throwaway
  `zz-probe` service (alpine, `networks: [services, data]`, healthcheck) —
  the probe resolved both networks declared in the root file; `aaas-data`
  rendered with `internal: true`.
- `make up` with the probe — pulled the image, created `aaas-data` and
  `aaas-services`, started the container and waited until healthy (1.2 s).
- `make ps`, `make status` — showed `zz-probe running (healthy)`.
- `docker network ls` — `aaas-data internal=true`, `aaas-services internal=false`.
- `make down` — removed the container and both networks; zero `aaas`
  containers left. Probe removed afterwards; it is not part of the repository.
- `make up` on the empty skeleton — "no services defined ... nothing to start.",
  exit 0.
- `make clean` — exit 0 (Compose warns that there is nothing to remove).
- `make lint` — passed (pre-commit skipped with the P0.5 notice, no
  `TEMPORARY` markers).
- `make build`, `make e2e`, `make doc-coverage`, `make docs` — not applicable
  (no services; tooling delivered by P1.9, P0.9, P0.10).
- English-only check: a recursive grep for Polish diacritics, excluding
  `CLAUDE.md` — no matches.

## Decisions
- ADR-0003: networks declared only in the root file, Docker names prefixed
  `aaas-`, `data` is internal (no egress), `make up` tolerates an empty model.
