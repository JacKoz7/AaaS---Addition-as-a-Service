## Goal
GitHub Actions: lint, build of changed services (matrix per directory), tests,
commitlint on PR. CI is green.

## What Was Done
- `.github/workflows/ci.yml`: triggers on push to `main` and `step/**`, on
  pull requests and on `workflow_dispatch` (input `all-components`). Jobs:
  `lint (repository)` (`make lint-repo lint-scaffold temporary` with
  `SKIP=no-commit-to-branch`, pre-commit cache), `commitlint` (PR range,
  push range, or commits not on `origin/main`), `detect changed components`,
  a matrix job per component (`make build-<service>`, `make lint-<name>`,
  `make test-<name>`, `fail-fast: false`) and the aggregate `ci-ok`.
  Actions pinned to commit SHAs (checkout v7.0.1, setup-python v7.0.0,
  setup-node v7.1.0, cache v6.1.0); `permissions: contents: read`;
  `concurrency` cancels superseded runs; runner `ubuntu-24.04`.
- `scripts/ci/changed-components.sh`: computes the matrix as JSON
  (`name`, Compose `service`, `path`) from `git diff BASE...HEAD`; global
  paths (`Makefile`, `docker-compose.yml`, `templates/service/`,
  `contracts/`, the workflow, `scripts/ci/`) select every component;
  deleted components are dropped; bash 3.2 compatible.
- `.pre-commit-config.yaml`: actionlint hook from the pinned Docker Hub image
  `rhysd/actionlint:1.7.12`.
- `docs/adr/0006-github-actions-ci.md`; README "Contributing" section and
  repository map updated.
- Local clone: `origin` switched from HTTPS to SSH
  (`git@github.com:JacKoz7/AaaS---Addition-as-a-Service.git`), because the
  `gh` OAuth token lacks the `workflow` scope required to push workflow files
  over HTTPS. This is local git configuration, not a repository change.

## Decisions
- ADR-0006: single workflow, changed-component matrix with global paths,
  SHA-pinned actions, actionlint as a Docker pre-commit hook, `ci-ok` as the
  status for branch protection.
- `ci-probe/*` branches are deliberately not push triggers; ad-hoc CI checks
  use `workflow_dispatch` on such a branch.
