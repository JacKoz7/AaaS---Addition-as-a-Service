## Goal
Document templates in `templates/docs/` (every document from CLAUDE.md 6.5.5),
a file header template per language, and `new-service.sh` copying them.

## What Was Done
- `templates/docs/`: `SERVICE_CHARTER`, `RACI`, `SLO`, `RUNBOOK`,
  `THREAT_MODEL`, `DATA_CLASSIFICATION`, `DEPENDENCIES`, `CAPACITY`, `API`,
  `CHANGELOG` (`*.md.tmpl`) plus `README.md`. Each has the corporate metadata
  table, the statements true for every service (team, database, memory limit
  and justification, healthcheck timing, network segmentation, error budget
  of 99.9% over 30 days = 43 min 12 s) and `TODO(scaffold)` markers for
  service-specific content.
- `templates/headers/`: canonical `header.txt`, `styles.psv` (42 file types:
  comment syntax, file matches, width, preamble), 42 generated `<type>.tmpl`,
  `README.md`.
- `scripts/file-header.sh`: `render` (team lookup, type detection from the
  path, wrapping to 72/80 columns, preamble), `detect`, `list`, `generate`,
  `check`. bash 3.2 compatible.
- `templates/service/catalog.psv`: the service catalog moved out of
  `new-service.sh`; both scripts read it.
- `scripts/new-service.sh`: always renders `templates/docs/` (fails if
  missing), new placeholders `__DATE__`, `__VERSION__`, values escaped for
  sed (`&`, `|`, `\`), next-steps message mentions documents and
  `file-header.sh`.
- `Makefile` `lint-scaffold`: `git grep` with root-relative exclusions.
- `.pre-commit-config.yaml`: `file-header-templates` hook
  (`scripts/file-header.sh check`); `templates/headers/` excluded from the
  shebang-executable check.
- Fix from P0.4: Compose `build.context` is `../services/<name>` (relative to
  `compose/`).
- ADR-0007; ADR-0004 marked as amended; README repository map.
