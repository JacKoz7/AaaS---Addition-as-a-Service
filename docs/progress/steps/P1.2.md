## Goal
`gateway` service: Traefik with file-based configuration (the Redis provider
follows in P5.4), routing of `/api` and `/`. Result: the gateway listens on
port 80.

## What Was Done
- `services/gateway` scaffolded with `make new-service NAME=gateway
  LANG=traefik`, then completed:
  - `config/traefik.yml`: entry points `web` (:8000, host `127.0.0.1:80`)
    and `internal` (:8080), aliased headers deleted, encoded reserved path
    characters rejected, 8 s shutdown grace, file provider, local plugin
    `edge`, Prometheus metrics on `internal`, JSON logs and access logs
    (only `traceparent` and `Idempotency-Key` headers kept), dashboard off.
  - `config/dynamic/routes.yml` (Go template): `/api/v1/keys` →
    expression-assembler, `/api/v1/tasks/{taskId}` → ledger
    (`TEMPORARY(P3.3)`), `/api` and `/api/...` otherwise → 404 problem,
    everything else → frontend-shell, `/health` on `internal`; upstream URLs
    from `AAAS_UPSTREAM_*`; 2 s dial and response-header timeouts; retry
    with 3 attempts.
  - `src/edge`: Traefik middleware plugin in Go (standard library only,
    interpreted by Yaegi) with modes `problem` (RFC 9457 rewriting of
    non-compliant API errors), `not-found` and `health`.
  - `tests/`: 8 unit tests of the plugin and the integration test
    `TestGateway` (9 subtests) running the real Traefik binary with the real
    configuration against stub upstreams.
  - `Dockerfile`: toolchain (Go 1.27.2, revive, godoclint built against
    x/tools v0.52.0, doc2go, Traefik binary), lint, test, doc-coverage,
    api-docs, build and the non-root `traefik:v3.7.14` runtime stages.
  - Component `Makefile` (`fmt` = `gofmt -w`, `run` on 8000/8080),
    `revive.toml`, `.godoc-lint.yaml`, `api-docs.html`, README and the ten
    documents of `CLAUDE.md` 6.5.5 with real content.
- `compose/services.yml`: gateway on `public` and `services`, port
  `127.0.0.1:80:8000`, upstream variables, 64 MB, health check; the
  scaffolded Redis container, volume and `.env.example` password removed
  (P5.4 adds them back).
- `templates/headers/styles.psv`: header style `gomod` (`go.mod`,
  `go.work`) and the generated `templates/headers/gomod.tmpl`.
- `Makefile`: `make temporary` skips the generated `build/` directory.
- `CLAUDE.md` (section 5 layout: `infra/redpanda/`, `infra/docs-portal/`
  instead of the unused `infra/traefik/`) and `CODEOWNERS`.
- Release `gateway` v0.1.0: `CHANGELOG.md` generated with
  `make changelog-gateway VERSION=0.1.0` plus the Business Impact section.
- ADR-0012.

## Decisions
- ADR-0012: configuration baked into the image under
  `services/gateway/config/` (not `infra/traefik/`); entry points 8000/8080
  with request hygiene; templated upstream URLs; Phase 1 routes only, later
  steps add theirs; local plugin `edge` for RFC 9457 errors and the JSON
  health endpoint; Go documentation coverage with revive + godoclint; no
  database until P5.4.

## Notes for the Next Session
- Each step that delivers a public endpoint adds its route to
  `config/dynamic/routes.yml` (with the `api-problem` and `api-retry`
  middlewares for API routes), an `AAAS_UPSTREAM_*` variable, a subtest in
  `tests/gateway_test.go`, and updates `docs/API.md` and `DEPENDENCIES.md`
  of the gateway.
- Upstream services must listen on port 8080 under their Compose service
  name on the `services` network (`expression-assembler`, `ledger`,
  `frontend-shell`).
- The Traefik log uses its own JSON field names; mapping to the AaaS log
  fields is planned for P7.1.
- Port 8000 on this workstation is held by an unrelated process; use
  `make docs-serve DOCS_PORT=8001`.
