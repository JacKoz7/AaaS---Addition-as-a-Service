## Goal
`expression-assembler` (C#, SurrealDB): `POST /api/v1/keys`, expression
assembly, event publishing, `202 {taskId}`. Result: key presses reach the
system.

## What Was Done
- **Contracts** (`contract(contracts)` commits):
  - new `aaas.key.pressed.v1` schema (payload `sessionId`, `key`, `seq`;
    `taskId` always null; keyed by `sessionId`) with 2 valid and 6 invalid
    examples;
  - `aaas.expression.submitted.v1`: description of `expression` corrected
    (a previous `=` also starts a new expression); constraints unchanged.
- **Service** `services/expression-assembler` (scaffolded with
  `make new-service NAME=expression-assembler LANG=csharp`), .NET 10,
  ASP.NET Core minimal API:
  - `POST /api/v1/keys`: validation (`KeyPressValidator`), idempotent
    recording per `(sessionId, seq)`, `aaas.key.pressed.v1`; on `=`:
    `Idempotency-Key` claim (`TEMPORARY(P6.3)`), expression assembly
    (`ExpressionBuilder`), task with UUIDv7, `aaas.expression.submitted.v1`,
    `202 {taskId}`; problems 400/405/409/422/503 (RFC 9457); 1.8 s request
    budget below the gateway timeout.
  - Events stored before publishing and marked published after the
    acknowledgement; retries republish the identical event.
  - SurrealDB over HTTP RPC with token authentication (`SurrealClient`),
    store (`SurrealAssemblerStore`), migration runner with
    `migrations/0001_initial_schema.surql` (tables `key_press`, `task`,
    `idempotency_key`, every field with `COMMENT`).
  - Kafka producer (Confluent.Kafka, idempotent, `acks=all`), `GET /health`

    OpenTelemetry tracing (OTLP export only when configured), 8 s shutdown.
  - Dockerfile: SDK noble toolchain; stages lint (dotnet format,

    `cyrus-sasl` for librdkafka, UID 10001).
  - 72 xUnit v3 tests (Microsoft.Testing.Platform runner via `global.json`):
    key service, validation, configuration, endpoints on TestServer,

    real SurrealDB process.
  - README and all 10 documents with measured figures; CHANGELOG 0.1.0 via

- **Compose**: `expression-assembler` (128m, depends on its database,

## Decisions
- [ADR-0014](../../adr/0014-expression-assembler-surrealdb-and-kafka.md):
  .NET 10 on Alpine with `cyrus-sasl`, SurrealDB over HTTP RPC with token
  authentication (Basic auth cost 25–50 ms per query: a key press took
  1.6 s under load), natural record keys and one transaction for exactly one
  task per `=`, stored events, 1.8 s request budget with shortened
  dependency timeouts, 128 MB memory class, generated events section of
  `API.md`.
- `aaas.key.pressed.v1` is keyed by `sessionId` and has `taskId: null`, as
  anticipated by ADR-0013.
