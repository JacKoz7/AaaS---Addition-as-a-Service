## Goal
`successor` (Haskell, CouchDB): `Next(n) = n+1` computed natively, marked
`TEMPORARY(P2.13)`. Result: the successor service answers.

## Decisions
- [ADR-0016](../../adr/0016-successor-haskell-couchdb-call-log.md):
  HTTP/JSON until P2.1 with `taskId` in the request; natural key
  `<taskId>:<n>` and the stored event make retries safe; answer only after
  the call is logged and the event acknowledged (1.8 s budget); CouchDB in
  its own image (a bind mount breaks its entry point); Basic
  authentication (CouchDB caches it, 4 ms per write); JSON migrations with
  a documentation object; delivery-report polling thread; ormolu, hlint,
  Haddock with `--ignore-all-exports`, doctests.
