## Goal
Temporary frontend: `frontend/shell` with one plain-JS page (keypad +
display), marked `TEMPORARY(P8.x)`. Result: 2+3= can be clicked.

## What Was Done
- **Page** `frontend/shell` (component `shell`, Compose service
  `frontend-shell`), plain ES modules without a build step:
  `calculator.js` (pure state machine: sessions, ordered sequence numbers,
  `Idempotency-Key` per `=`, 64-character limit, phases input → waiting →
  done/error), `api.js` (`POST /api/v1/keys` with 2 s deadline and 3
  attempts, `GET /api/v1/tasks/{taskId}`), `ids.js` (UUIDv4 from
  `getRandomValues`), `app.js` (browser event bus `aaas:key-pressed`,
  `aaas:clear`, `aaas:task-started`, `aaas:task-finished`; keys sent in
  order; polling every second; `Error` after 15 s unknown,
  `TEMPORARY(P3.6)`), `main.js` (keypad), `index.html`, `style.css`,
  `favicon.svg`; `TEMPORARY(P8.15)` throughout.
- **Serving**: unprivileged nginx 1.30.6 (UID 101, port 8080), strict CSP and
  security headers, JSON access log, `/health` and `/metrics` answering 404
  to requests forwarded by the gateway.
- **Tooling**: Node.js 24 toolchain with pinned ESLint 10,
  eslint-plugin-jsdoc (JSDoc required on every definition with the fields of
  6.5.3, checked by `jsdoc/no-restricted-syntax`), Prettier, JSDoc
  (`--pedantic`); Dockerfile stages lint, test, doc-coverage, api-docs,
  runtime (90 MB); Makefile `test` also checks the running runtime image
  over HTTP.
- **Compose**: `frontend-shell` in `compose/frontend.yml` (`public` network,
  64m, health check).
- **Repository**: `.prettierignore` header type; ADR-0018; glossary
  (browser event bus); onboarding (open the calculator).
- README and all 10 documents; CHANGELOG 0.1.0 via git-cliff plus Business
  Impact.
