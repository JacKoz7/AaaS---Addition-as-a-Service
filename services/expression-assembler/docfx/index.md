# expression-assembler API

Native API documentation of the `expression-assembler` service, generated by
DocFX from the XML documentation comments of every type and member, private
members included. The service turns key presses of the calculator into an
expression and starts a task (`CLAUDE.md` 3, step 2).

Start with [`KeyService`](../api/AaaS.ExpressionAssembler.Keys.KeyService.yml),
which implements `POST /api/v1/keys`. The HTTP contract is described in
`services/expression-assembler/docs/API.md`.
