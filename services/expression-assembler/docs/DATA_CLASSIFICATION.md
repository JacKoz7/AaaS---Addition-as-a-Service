## 1. Classification Levels

| Level | Meaning |
| --- | --- |
| PUBLIC | May be shown to anyone (for example the result of 2 + 3) |
| INTERNAL | Operational data of AaaS; not shown to users |
| CONFIDENTIAL | Credentials, tokens and identifiers linkable to a person |

## 2. Data Inventory

Store: SurrealDB in `expression-assembler-db`, volume
`expression-assembler-data`. Schema: `migrations/0001_initial_schema.surql`.

| Data Item | Location | Classification | Retention | Personal Data |
| --- | --- | --- | --- | --- |
| `sessionId` (random UUID per calculator session) | `key_press.session_id`, `task.session_id`, events, record keys | INTERNAL | Until the volume is removed (`make clean`); Redpanda topics: 7 days | Pseudonymous identifier; not linkable to a person while AaaS has no accounts (guest login from P6.1 is anonymous; see DPIA) |
| Pressed keys and their order (`key`, `seq`), expressions (`2+3`) | `key_press`, `task`, events | INTERNAL | As above | No (numbers typed into a calculator) |
| Reception and submission times | `key_press.received_at`, `task.submitted_at`, events | INTERNAL | As above | No |
| `Idempotency-Key` values | `task.idempotency_key`, `idempotency_key` record keys | INTERNAL | As above | No (random values generated by the frontend) |
| Task identifiers (UUIDv7) | `task`, `key_press.task_id`, events, logs | INTERNAL | As above | No |
| Serialized events (envelopes) | `key_press.event`, `task.event` | INTERNAL | As above | As the fields they contain |
| `traceparent` values | Records, events, logs | INTERNAL | As above; Loki and Jaeger from Phase 7 | No |
| Database password | Environment (`EXPRESSION_ASSEMBLER_DB_PASSWORD`), `.env` on the host | CONFIDENTIAL | Until rotated; moves to OpenBao in P5.3 | — |
| SurrealDB session token | Process memory only, renewed hourly | CONFIDENTIAL | Never written | — |
| Prometheus metrics (counts per key, outcome, topic) | `/metrics` | INTERNAL | Prometheus retention from P7.1 | No |

No retention job exists in 0.1.0: stored presses and tasks are kept until the
volume is deleted. The measured footprint is about 4 KB per key press on disk
(CAPACITY.md); the growth is registered as R-012 in
`docs/governance/RISK_REGISTER.md`.

## 3. Handling Rules

- Data is never read by another service directly (`CLAUDE.md` section 1,
  rule 4); others receive it only through the events listed in API.md.
- Stored presses are never shown to users: AaaS has no calculation history
  (`CLAUDE.md` section 1).
- CONFIDENTIAL values are never logged; error details returned to clients do
  not contain internal host names or database messages.
