gateway — API documentation

The gateway is Traefik with a file-based configuration and one local middleware plugin, edge, written in Go. Platform Enablement Guild (PEG).

  • edge plugin reference (Go doc comments, generated by doc2go)
  • config/traefik.yml: static configuration (entry points, provider, plugin, metrics, logs)
  • config/routes.yml: routes, middlewares and upstream services (Go template)
  • Traefik v3.7 reference (upstream)

The public routes and error format are described in services/gateway/docs/API.md.
